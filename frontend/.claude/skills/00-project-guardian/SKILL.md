# Skill: COMPNET Project Guardian

Use this skill at the beginning of every task.

## Mission
Protect the project from uncontrolled changes and keep Phase 1 frontend-only.

## Instructions
1. Inspect the current folder structure first.
2. Confirm the active Next.js root by locating `package.json`, `src/app` or `app`.
3. Do not create backend folders or services.
4. Do not move many files without explaining why.
5. Do not replace working configuration unless necessary.
6. Preserve existing user work.
7. Make one logical step at a time.
8. After each step, provide the exact browser path to verify.

## Required response format
- Current state
- Planned files
- Changes
- Verification
