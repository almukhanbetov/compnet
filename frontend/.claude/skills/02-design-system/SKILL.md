# Skill: COMPNET Design System

## Visual identity
Create a premium AI-commerce visual language.

## Principles
- Dark-first interface with optional light mode later.
- One dominant gradient family: violet → blue → cyan.
- Use pink only as a small accent.
- Use glow sparingly around hero and primary CTAs.
- Avoid random colors across sections.
- Keep content readable over decorative backgrounds.

## Components
Define reusable patterns for:
- container
- section heading
- badge
- primary button
- secondary button
- glass card
- stat card
- icon tile
- gradient text

## Layout
- full-width page background
- content max width 1280–1440px
- generous vertical rhythm
- responsive spacing
- no horizontal overflow

## Accessibility
- visible focus states
- semantic headings
- contrast-compliant text
- buttons and links must have clear labels
- decorative SVGs must be hidden from screen readers
