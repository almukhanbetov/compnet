# Skill: UI Interactions and Motion

## Allowed
- hover and focus states
- mobile menu
- tabs
- accordions
- filters using local state
- carousels
- modal previews
- animated section entrances
- counters with static values

## Motion rules
- Use `motion/react`.
- Prefer opacity and transform animations.
- Keep duration subtle.
- Respect reduced motion.
- Avoid constant distracting animation.
- Do not animate large background layers continuously on low-end mobile.
