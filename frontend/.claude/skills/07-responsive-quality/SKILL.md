# Skill: Responsive Quality

## Test widths
- 375px mobile
- 768px tablet
- 1024px small desktop
- 1440px wide desktop

## Checklist
- no horizontal scrolling
- readable headings
- buttons remain tappable
- cards stack correctly
- grids reduce columns logically
- header becomes mobile menu
- images keep aspect ratio
- spacing stays balanced
- fixed and sticky elements do not cover content
