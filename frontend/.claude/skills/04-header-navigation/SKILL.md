# Skill: Header and Navigation

## Build
- announcement bar
- logo area
- desktop navigation
- login and register actions
- theme button placeholder
- mobile menu button
- mobile drawer

## Rules
- Sticky header with backdrop blur.
- Active route state should be visually clear.
- Mobile menu must not overflow viewport.
- Do not link to missing backend actions.
- Missing pages may link to visual placeholder routes.
- Use Lucide icons where useful.
