# Skill: Chat Prototype

## Goal
Create a polished chat UI without WebSocket or backend.

## Include
- conversation list
- search conversations
- active conversation header
- message bubbles
- timestamps
- unread counters
- attachment UI
- emoji button placeholder
- send box with local-only behavior
- empty state

## Rules
- Use mock messages.
- Keep local interaction isolated in a client component.
- Do not create socket connections.
- Do not create API routes.
