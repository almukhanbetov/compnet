# Skill: Homepage Builder

## Goal
Build the homepage section by section without lowering quality.

## Required sections
1. announcement bar
2. header
3. hero
4. trusted-by or platform metrics
5. popular categories
6. featured offers
7. benefits
8. how it works
9. analytics preview
10. testimonials
11. latest articles
12. CTA section
13. footer
14. floating chat button

## Process
For each section:
1. show component name and file path;
2. create typed mock data if needed;
3. implement desktop version;
4. implement tablet/mobile behavior;
5. verify spacing, contrast and overflow;
6. stop and report before continuing to the next major section.

## Hero requirements
- wide layout
- strong headline
- two CTA buttons
- AI-themed background
- dashboard or commerce preview card
- subtle motion
- no heavy autoplay video
